# Dot Awkward

Small games for odd moments. The studio page at https://dotawkward.github.io/

- [Small Plates](https://dotawkward.github.io/small-plates/), a word game for one or two
- [Sprout](https://dotawkward.github.io/plant-app-site/), a game about keeping real houseplants alive

This repo is only the home page. Each game lives in its own repo and is served under its own path.
